# House of Wolves gym app (preview)

Working prototype of the member and coach app for CrossFit House of Wolves, Livingston.

- Member side: classes and plan rules, waitlists, Open Gym with kit booking, whiteboard, scores, PRs, join flow.
- Coach side: dashboard, check-in, programming, timetable, Open Gym board, members, leads, settings.

This is a front-end preview. Data is saved in the browser only (localStorage). The production build adds a database, logins, payments and notifications.

Hosted with GitHub Pages from `index.html` on `main`.
