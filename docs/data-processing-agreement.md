# Data processing agreement (template)

Template only. Have it checked by a solicitor before signing.

**Between**
- **[Gym legal entity name]**, trading as CrossFit House of Wolves ("the Controller"), and
- **Gerard Queen** ("the Processor"), who builds, hosts and supports the House of Wolves app.

**1. Subject and duration.** The Processor provides and maintains the app for as long as the support arrangement runs. When it ends, the Processor hands over or deletes the Controller's data within 30 days, as the Controller chooses.

**2. Data and people.** Members', leads' and staff's personal data as described in the privacy notice, including health information (special category data).

**3. Instructions.** The Processor only processes personal data on the Controller's documented instructions, which include running the app as described in the privacy notice.

**4. Confidentiality.** Anyone the Processor allows to access the data is bound by confidentiality.

**5. Security.** Data is encrypted in transit and at rest by the hosting provider. Access is limited by database rules so members only see their own data. Admin keys are kept out of the app code. Access to the hosting accounts uses two-factor authentication.

**6. Sub-processors.** The Controller approves: Supabase (database, sign-in, functions), Stripe (payments), GitHub (app hosting, no member data), and the email sender used for sign-in emails. The Processor will tell the Controller before adding or replacing a sub-processor, and the Controller may object.

**7. Assistance.** The Processor helps the Controller respond to data rights requests, carry out data protection impact assessments if needed, and meet its security obligations.

**8. Breaches.** The Processor tells the Controller without undue delay, and within 24 hours of becoming aware, of any personal data breach, with the details the Controller needs to report it.

**9. Audits.** The Processor provides the information needed to show it complies with this agreement.

**10. Accounts.** Hosting, payment and app store accounts are held in the Controller's name. The Processor has delegated access only.
